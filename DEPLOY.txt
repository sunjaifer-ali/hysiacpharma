Hysiac Management App — GitHub + Vercel + Neon
================================================

This is the only way the app runs. Do not install a Windows, Android or iPhone copy.

The live site is https://hysiacpharma.vercel.app
Bills, products, parties and users are stored in Neon. A phone, tablet, laptop and desktop all open that same site.

1. Neon
   - Open https://neon.tech and use the free project for this app.
   - Copy the pooled connection string:
     postgresql://USER:PASSWORD@HOST/neondb?sslmode=require

2. GitHub
   - The source is the repository connected to Vercel.
   - Do not commit node_modules.
   - Push to the main branch. Vercel deploys from that push.

3. Vercel
   - Project connected to that GitHub repository.
   - Framework is detected from the repository. Build command is npm run build.
   - Environment variables, for Production and Preview:

     DATABASE_URL          the Neon pooled connection string
     VITE_AUTH_ENABLED     true
     BETTER_AUTH_SECRET    a long random password, at least 32 characters
     BETTER_AUTH_URL       https://hysiacpharma.vercel.app

   - Redeploy after changing any variable.
   - The first request creates the tables in Neon.
   - Sign in, then change the admin password under Users.

If sign-in says the origin is not allowed, set BETTER_AUTH_URL to the exact
address in the browser, including https, and deploy again.

Without DATABASE_URL the live site will not open the books. It does not keep
a separate copy on the server.
