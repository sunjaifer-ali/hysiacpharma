Hysiac GST — Windows app
========================

1. Unzip this folder anywhere (Desktop, Documents, a USB drive).
2. Double-click "Hysiac GST.exe".
3. Windows may ask to allow an unknown app the first time — choose More info, then Run anyway.

Your books (invoices, stock, parties) are saved in the "Hysiac-GST-data" folder
that appears next to the .exe. Copy the whole unzipped folder (including that
data folder) if you move the app to another PC or a USB drive.

Settings → Export JSON also writes a backup file you can keep separately.

Google Drive backup is in the online (published) app, not this .exe.

Print uses this PC's printers.
